# wrapsql

Wrap CSV/TSV sql tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/wrapsql/

## Install / run

```bash
git clone https://github.com/theworker02/wrapsql.git
cd wrapsql
node src/cli.js
node --test
```
